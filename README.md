# Project UMBRAL

> **The world remembers.**

UMBRAL is a design-led game project. Gameplay, content, and technical decisions are governed by the Design Bible. Until a decision is recorded there or in `DECISIONS.md`, this repository uses neutral placeholders.

## Start here

Requirements: Python 3.11+ and Git.

```bash
python3 tools/umbral.py check
```

## Repository map

- `docs/` — studio, design, development, operations, and references.
- `game/`, `server/`, `shared/` — future implementation boundaries; intentionally empty.
- `assets/` — source assets.
- `tools/` and `scripts/` — versioned developer tooling.
- `prompts/` — reviewed AI workflow templates.

Read [the Studio Charter](docs/00_STUDIO_CHARTER.md) and [CONTRIBUTING.md](CONTRIBUTING.md) before contributing.
