# Project UMBRAL Studio Charter

> We are not building an MMORPG. We are building a world.

Every system exists to make that world more believable, memorable, and alive. If a feature does not make the world better, it does not belong.

## Operating principles

- Design precedes implementation.
- The Design Bible is authoritative for gameplay and world decisions.
- Technical work must be reproducible, documented, and reviewable.
- Infrastructure enables future work without silently deciding it.
