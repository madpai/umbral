# Architecture Documentation

This directory contains the evolving technical architecture for UMBRAL. It is
intentionally technology-neutral until decisions are reviewed and recorded.

- [Overview](OVERVIEW.md) — system boundaries and cross-cutting concerns.
- [Client](CLIENT.md) — player-facing application responsibilities.
- [Server](SERVER.md) — authoritative and service-side responsibilities.
- [Database](DATABASE.md) — durable-data responsibilities and data boundaries.
- [Networking](NETWORKING.md) — communication contracts and runtime concerns.
- [AI Systems](AI_SYSTEMS.md) — future AI-assisted or simulated-system boundaries.

Record approved technical decisions in [DECISIONS.md](../../DECISIONS.md).
For major decisions that need durable context, alternatives, and consequences,
use the [Architecture Decision Record framework](../decisions/README.md).
