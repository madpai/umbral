# AI Collaboration Workflow

## Purpose

This document defines intended responsibilities for AI-assisted work in UMBRAL.
These responsibilities guide collaboration; project owners retain review and
approval authority.

## Intended Responsibilities

### ChatGPT

- Architecture
- Design review
- Prioritization
- Planning

### Claude

- Implementation
- Refactoring
- Code generation

### Codex

- Repository operations
- Tooling
- Automation
- Infrastructure changes

### Grok

- Narrative exploration
- Lore generation
- Creative ideation

## Collaboration Rules

- AI agents must not override documented decisions without review.
- Major architecture changes require corresponding documentation updates.
- Record design decisions before implementation begins.
- Use `DECISIONS.md` for consequential technical and process decisions; use the
  Design Bible for design decisions.
- Treat unrecorded decisions as open questions, not authorization to choose an
  implementation or mechanic.
