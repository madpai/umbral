# Development Standards

- Prefer small, cohesive modules with explicit ownership.
- Keep generated files out of version control unless documented otherwise.
- Never commit credentials, tokens, personal data, or build artifacts.
- Update verification when changing tooling.
- Use UTF-8, LF line endings, and `.editorconfig`.

Language, formatter, linter, test framework, engine, asset, and schema standards are deferred pending approved technical decisions.
