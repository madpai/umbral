# Contributing to Project UMBRAL

1. Read `docs/CANON.md` first, then `docs/00_STUDIO_CHARTER.md` and relevant approved Design Bible material.
2. Do not introduce gameplay, lore, balance, or content decisions without an approved source.
3. Record material technical decisions in `DECISIONS.md`.
4. Keep changes focused, documented, and verified with `python3 tools/umbral.py check`.

Use concise imperative commit subjects, for example: `Add repository validation command`.

See [Development Standards](docs/development/STANDARDS.md) for baseline practices.
